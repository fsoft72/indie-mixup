# LiWE3 Frontend Library

The `@frontend/liwe3` package exposes reusable Svelte components, layouts, and utility helpers that complement the LiWE3 backend services.

## Overview

- **Components** – Shared UI building blocks for dashboards, tables, and forms.
- **Utilities** – Helpers for formatting, validation, and shared state management.
- **Styles** – Design tokens and layout primitives that keep applications visually consistent.

## Getting Started

1. Install the package via `pnpm add @frontend/liwe3` in your consuming project.
2. Import components or helpers from `@frontend/liwe3` and follow their documented usage examples.
3. Compose frontend experiences alongside backend modules for a cohesive LiWE3 application.

## Documentation

Check each component's readme (e.g., `/frontend/liwe3/button.md`) for specific guidelines and API details.
